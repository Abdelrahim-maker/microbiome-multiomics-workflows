Data Preparation and Mapping Audit

Build targeted feature matrices from annotation and mapped reads, then verify sample-metadata consistency.

Back to homepage

What this project does

Defines carbon-target labels, links annotated loci to MAG catalog IDs, aggregates mapped reads into direct TPM-like feature tables, and checks sample-level metadata alignment.

Key scripts

  • scripts/prepare.py - Main preparation pipeline for direct and inferred feature matrices.
  • scripts/mapping_audit.py - Additional mapping and provenance checks.
  • scripts/validate.py - Validation utilities and consistency checks.

Primary outputs

  • inputs/GC_direct_gene_TPM.tsv
  • inputs/OSS_direct_gene_TPM.tsv
  • tables/image_gene_locus_cluster_MAG_taxonomy.tsv
  • tables/sample_matching_audit.tsv
