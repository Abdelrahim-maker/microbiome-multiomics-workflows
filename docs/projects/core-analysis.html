What this project does

Fits adjusted models at gene/pathway/mechanism/MAG levels, performs treatment and interaction contrasts, and runs permutation-based multivariate community tests with FDR control.

Key scripts

  • scripts/analyze.py - Primary analysis engine.
  • scripts/sensitivity.py - Robustness and design sensitivity checks.
  • scripts/validate.py - Post-analysis consistency checks.

Primary outputs

  • Model and community-level highlights
  • Competency mapping and internship relevance summary
