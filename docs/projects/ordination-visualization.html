What this project does

Builds ordinations from direct gene/pathway/MAG abundance profiles, then visualizes treatment effects and contextual separation while keeping full-space inferential tests in companion tables.

Key scripts

  • scripts/ordination_OM_by_shrub.py - GC OM ordinations split by shrub state.
  • scripts/network_analysis.py - Additional structure-level visualization/analysis.
  • scripts/analyze.py - Produces baseline ordination score outputs.

Primary outputs

  • GC OM-by-shrub stratified ordination figure
  • Additional ordination-related highlights
  • Access scripts that generate ordination outputs
