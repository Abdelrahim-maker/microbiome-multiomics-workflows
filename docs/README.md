# Internship Portfolio Site

This folder is a static GitHub Pages site that presents your work by project, while keeping your existing analysis code unchanged.

## Quick publish steps

1. Push this repository to GitHub.
2. Open repository Settings -> Pages.
3. Under Build and deployment, set Source to Deploy from a branch.
4. Select branch main and folder /portfolio_site.
5. Save and wait for the site URL.

## Site structure

- index.html: Portfolio landing page.
- styles.css: Shared style sheet.
- projects/: Project pages with methods, script links, and outputs.

## Add a new project

1. Duplicate a page in projects/.
2. Add a new project card link in index.html.
3. Add script links and one key output figure/table.
4. Commit and push.

## Notes

- Existing scripts and outputs stay in place; this site references them.
- Keep file names stable if you already shared links in an application.
