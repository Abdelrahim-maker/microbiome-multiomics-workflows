About Me

I build reproducible bioinformatics pipelines for metagenomic functional profiling, statistical modeling, and publication-ready reporting. This portfolio is organized so internship reviewers can quickly evaluate project scope, technical depth, and biological interpretation.

Current focus: carbon-function signals across GC and OSS studies using direct mapped-read feature tables, factorial treatment modeling, and validated visual summaries.

How This Site Is Organized

Scripts are grouped by project objective instead of file type. This makes it easy for internship reviewers to see the problem, method, code, and result in one place.

  • Each project page links to key scripts and one or two result outputs.
  • Code remains in its original location; this site is a presentation layer.
  • Pages can be deployed directly from the portfolio_site folder in GitHub Pages.
